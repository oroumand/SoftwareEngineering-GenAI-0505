## T036 — OpenAPI و تطبیق قرارداد

OpenAPI برنامه را با امکانات استاندارد ASP.NET Core تکمیل کن.

Endpointهای Author، Editor و Public را از نظر Metadata و قرارداد بررسی کن.

خروجی واقعی API را با:

`specs/001-blog-post-management/contracts/http-api.md`

تطبیق بده.

موارد زیر باید بررسی شوند:

- مسیرها و HTTP Methodها
- Request DTOها
- Response DTOها
- Bearer Authentication
- If-Match / ETag
- status codeها
- ProblemDetails
- `code`های پایدار خطا
- PublicPostView
- PostView
- allowedActions

Swagger UI یا Package نمایشی جدید اضافه نکن؛ فقط OpenAPI موردنیاز Plan را ایجاد کن.

اگر Implementation با قرارداد اختلاف دارد، ابتدا مشخص کن کدام‌یک منبع معتبر است.

اگر اختلاف ناشی از Implementation است، کد را اصلاح کن.

اگر اختلاف ناشی از نقص Artifact طراحی است، بدون گزارش وارد تغییر قرارداد نشو.

## T037 — واقعی‌کردن quickstart.md

فایل:

`specs/001-blog-post-management/quickstart.md`

فقط دستورهایی را ثبت کن که واقعاً روی Repository فعلی اجرا و تأیید کرده‌ای.

حداقل شامل:

- بررسی .NET SDK
- restore
- tool restore
- ایجاد یا اعمال Migration
- build
- test
- اجرای API
- مسیر و پیکربندی SQLite
- نحوهٔ Provision کاربران آزمایشی
- نحوهٔ دریافت و نگهداری Credential
- نحوهٔ Revoke کردن Credential یا Permission
- نمونهٔ درخواست‌های Author
- نمونهٔ درخواست‌های Editor
- نمونهٔ Public Read
- دریافت ETag

Quickstart باید امکان Demo کردن مسیر اصلی زیر را فراهم کند:

Author:
Create → Edit → Submit

Editor:
Request Changes → Submit again → Approve → Publish

Public:
Read Published Post

و همچنین حداقل چند Failure مهم:

- Unauthorized
- Self Approval
- stale Version
- Published mutation
- Private Post access

Secret یا Credential واقعی را در فایل ثبت نکن.
